## 第一周验收清单

- [ ] 成员 A　交付至少一组预实验样例，包含 `rgb.png`、`depth_raw.npy`、`depth_m.npy` 和 `meta.json`。确认对齐深度与彩色图的高宽一致，单位为米，缺测为 `NaN`。
- [ ] 成员 A　核对 `meta.json` 中的分辨率、SDK 版本、深度比例和帧时间戳。在 [实验记录](experiment-log.md) 登记曝光设置、前后景深度读数、有效深度占比、直边偏差和数据位置，补记场景编号、两个焦点坐标及配置版本。
- [ ] 成员 B　让 M0 在至少一个合成场景上输出两个不同焦点的结果。
- [ ] 两人　用约定接口离线加载同一个实拍样例，确认 M0 能输出前、后景分别合焦的结果。

## 数据交接约定

每组样例至少包含彩色图、原始深度帧、对齐深度数组和元数据。对齐深度用米制浮点数组，未知值为 `NaN`。元数据记录场景编号、帧时间戳、焦点坐标和配置版本。
